Meeting script

  1. Open Course A and show the prepared wrapper shell.
  2. Explain that staff edit only the visible course content in Brightspace.
  3. Return here and change Course A to Published.
  4. Show that it appears in the Learning Hub preview.
  5. Click the published course and show the learner-facing LACE wrapper.
  6. Open Brightspace Ready and run a preflight check on the course folder.
  7. Optional: open LACE Course Studio to show shell creation and topic editing.
